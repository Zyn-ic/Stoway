# StowayClientV3

Fusion client: snapshot boot, settings-driven hotbar + sectioned storage,
drag + drop, multi-platform input, skins. Two layout engines
(`StandardHotbarStorage`, `JailbreakHotbar`) share `Layouts/Shared`; skins
are thin prefab loaders.

Full write-up lives in the site: Skins & Layouts, Client Events & Hooks,
Architecture.
